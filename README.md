> *"Knowledge is power, guard it well."*

Welcome to **Librarium Imperialis**, the definitive open-source repository for tracking and cataloging your journey through the vast, grim-dark literature of the Warhammer universes. Whether you are trekking through the Horus Heresy, exploring the Mortal Realms, or surviving the 41st Millennium, this tool is built to ensure no chronicle is lost to the Warp.

---

## 🏛 Project Focus
The Librarium is designed to solve a problem every Warhammer fan faces: **"What have I read, and what comes next?"** This project aims to provide a structured, community-driven database and tracking system for:
* **The Horus Heresy & Siege of Terra**
* **Warhammer 40,000 (Dawn of Fire, Dark Imperium, and more)**
* **Warhammer Age of Sigmar**
* **The Old World & Warhammer Chronicles**
* **Novellas, Short Stories, and Audio Dramas**

## 🤝 A Community Effort
This is an open-source project created by fans, for fans. The goal is to build a comprehensive "Living Record." We believe that the lore belongs to the community, and its tracking should be just as collaborative.

### Why contribute?
The Black Library is massive. New books, limited editions, and obscure short stories are released constantly. No single servitor can track them all. We need your help to keep the Librarium updated.

---

## 🛠 How You Can Help

### 1. Report Missing Books
Found a missing novella? A newly released Omnibus? 
* **Open an Issue:** Tag it with `[Missing Content]`.
* **Provide Details:** Title, Author, Series, and Release Year.

### 2. Feature Requests
Want a progress bar for the Horus Heresy? A "Reading Order" toggle? 
* **Open an Issue:** Tag it with `[Feature Request]`.
* **Discuss:** Share how you think the feature should work.

### 3. Code Contributions
If you are a developer or data enthusiast, feel free to fork the repo and submit a Pull Request!
